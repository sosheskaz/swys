# Compute a SHA-256 digest

Hash a file or stdin with SHA-256. The default output is a hexadecimal digest followed by a newline, with no filename attached.

## Compare the bytes you have

Create a small input and save its digest. Compare the printed value with an expected SHA-256 value obtained from a trusted source.

```sh
printf 'hello' > message.txt
swys hash sha256 < message.txt
swys hash sha256 < message.txt > message.sha256
```

The input is read exactly as supplied, including any trailing newline. Hashing does not encrypt the message or derive a password-based encryption key.

## Match another tool's representation

Use an output encoding when a peer expects something other than hexadecimal. Raw output contains the 32 digest bytes with no appended newline.

```sh
swys hash sha256 --encoding base64 < message.txt
swys hash sha256 --encoding raw < message.txt > digest.bin
```

Input decoding is separate from output encoding. This hashes the decoded bytes of hello, producing the same digest as the file above.

```sh
printf 'aGVsbG8=' | swys hash sha256 --input-encoding base64
```

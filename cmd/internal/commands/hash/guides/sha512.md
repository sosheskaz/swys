# Compute a SHA-512 digest

Hash a file or stdin with SHA-512 when a peer or published checksum specifies that algorithm. Compare like algorithms; SHA-512 and SHA-256 produce different digests for the same input.

## Hash a file or message

Create a small file, save its hexadecimal digest, and hash the same bytes through stdin.

```sh
printf 'hello' > message.txt
swys hash sha512 < message.txt > message.sha512
printf 'hello' | swys hash sha512
```

Text output includes a final newline and no filename. The input is hashed exactly, so adding a newline to the message changes its digest.

## Write digest bytes for another tool

Raw output is 64 bytes with no appended newline. It is the digest, not a copy of the input.

```sh
swys hash sha512 --encoding raw < message.txt > digest.bin
```
